Moose brings local models, cloud providers and your conversations into one native Linux app. Start with the installation guide, then choose Moose-managed Ollama or connect a provider. These guides cover Ollama and Hugging Face model downloads, engine updates and repairs, custom connections, files, privacy and building from source. If something goes wrong, the getting started guide explains how to retry downloads and find logs and error details.
