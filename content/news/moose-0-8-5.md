Ask Moose for a report, put together a budget or turn an answer into a presentation. Version 0.8.5 adds **Create Document** to the chat, so you can go from a request to a file you can open and save.

Choose a name and format, then describe what you need. The dialog has examples for reports, letters, budgets and slides to help you get started. If you already have an answer you want to keep, use **Create Document from Response** beneath it and choose a format.

Moose can create PDF, Word, Excel, PowerPoint and OpenDocument files, as well as Markdown, plain text, CSV, HTML, JSON and XML. The files stay with the answer. You can preview their contents, open them in another application to see the final layout, or save a copy to your computer.

You'll also find them in **Files**, together with your uploads. Select **Generated** to see the documents you've created, or search by name, contents or chat title. **Open Chat** takes you back to the answer behind a document, even when it belongs to an earlier version of the conversation. File cards have a more compact layout to make browsing easier.

When you export a conversation, JSON now includes copies of created documents. Markdown and plain text include their names and formats. Your sources and tool results still go with the chat too.

We've also made attachments more comfortable to use. They leave more room for writing, and sent documents show their type and size, with page counts for PDFs. Open an image to fit it to the window or view it at its original size, then use the buttons or arrow keys to browse the other images in that message. We also fixed a freeze when pasting images on X11.

Finding a model is quicker when you know its name: both the chat model picker and the **Preferred Model** list in Chat Settings now support search.
