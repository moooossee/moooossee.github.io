Moose 0.7.0 makes it easier to look after your local AI setup. Open **Preferences → Ollama & Diagnostics → Manage Ollama** to check for engine updates, install a newer version or repair the current installation. Your models, chats and connections stay put. This release includes Ollama 0.40.6.

If an engine download stops, you can pick up where you left off. Moose checks the new engine before finishing an update and brings back the previous installation if something goes wrong. When a model download needs a newer Ollama version, you can update managed Ollama and retry from the error dialog.

There are also better ways to see what went wrong. You can open recent Moose and Ollama logs from Preferences and copy them when reporting a problem. Model download and deletion details have copy actions too. The setup screens for local and cloud connections have been tidied up.

The chat got a few fixes as well. Tables fit their content better and can be copied as Markdown. Chat bubbles size correctly, and dragging a text selection toward the edge scrolls the conversation so you can keep selecting a long passage.

Read the [0.7.0 release notes](@/changelog/0-7-0.md), learn how to [update or repair Ollama](@/docs/models-and-providers.md#update-or-repair-managed-ollama), or [get started with Moose](@/docs/getting-started.md).
