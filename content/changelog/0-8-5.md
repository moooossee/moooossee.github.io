The new **Create Document** action lets you describe what you need and choose a file name and format. Start a report, a budget or a presentation, or use **Create Document from Response** to turn a finished answer into a file. The dialog includes examples for reports, letters, budgets and slides.

Choose PDF, Word, Excel, PowerPoint or OpenDocument formats, along with Markdown, plain text, CSV, HTML, JSON and XML. Finished files stay saved with the response. **Preview** shows their contents, **Open** opens the file in another application, and **Save As…** saves a copy wherever you choose.

Created documents now appear in **Files**, alongside uploads. The new **Generated** filter helps you find them, and search also checks their contents and chat titles. **Open Chat** takes you back to the response that created a document, including an earlier answer version. The browsing layout has been updated with more compact file cards.

Conversation exports now include created documents. JSON keeps copies of the files and their details; Markdown and plain text list their names and formats. Document source excerpts, tool results and web sources remain part of exports too.

Attachments take up less space while you write. Sent documents show their file type and size, with page counts for PDFs. Image previews can fit the window or show the original size, with buttons and arrow keys to move through the images in a message. Pasting images on X11 no longer freezes the interface.

You can also search by part of a model's name in the chat model picker and the **Preferred Model** list in Chat Settings. The composer layout and document actions have been tidied up.

Learn how to [create a document](@/docs/files-and-documents.md#create-a-document), [find generated files](@/docs/files-and-documents.md#the-files-view), or [export a conversation](@/docs/files-and-documents.md#export-a-conversation).
