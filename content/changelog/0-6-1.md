Mistral AI and DeepSeek join the built-in cloud providers. Supported models also get reasoning controls.

Custom connections let you choose your own server address, API format and authentication method. Use a service compatible with OpenAI Chat Completions, OpenAI Responses, Anthropic Messages or Google Gemini.

Discover models automatically or save their exact IDs yourself. You can configure image support for each manual model, and saved models remain available if discovery is unavailable.

This release also fixes managed Ollama installation in folders accessed through symbolic links.
