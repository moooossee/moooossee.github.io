You can now check for updates, update or repair the Ollama installation managed by Moose right from Preferences. Your models, chats and connections stay put. The included Ollama release is now 0.40.6.

- Engine downloads can resume after an interruption. You can cancel before installation begins and pick up the download later.
- Moose checks the new engine before finishing an update and restores the previous installation if the update fails.
- If a model needs a newer engine, **Update Ollama and Retry** lets you update managed Ollama and try the download again.
- **Preferences → Ollama & Diagnostics** now includes recent Moose and Ollama logs that you can view and copy. Model download and deletion details are easier to copy too.
- The setup screens for managed Ollama, existing servers and cloud providers are clearer and more consistent.
- Tables fit better in chats and have a button to copy them as Markdown, including while an answer is arriving.
- Chat bubbles size correctly. Dragging a text selection toward the top or bottom edge of the chat scrolls the conversation so you can keep selecting.

See [how to update or repair Ollama](@/docs/models-and-providers.md#update-or-repair-managed-ollama) or [find logs and error details](@/docs/getting-started.md#need-help).
