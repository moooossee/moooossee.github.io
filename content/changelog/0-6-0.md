Connect securely to cloud providers with your own API key and control what you share.

- **Local Only mode** restricts inference to Ollama managed by Moose.
- **Separate sharing permissions** for messages and files. Review context before sending, allow messages per provider or per chat, and reset permissions in Privacy settings.
- **Files in the sidebar** brings attachments and library documents together. Browse, search, filter, preview, find the original folder, or reopen a related chat.
- **More local models** for chat, vision, reasoning, and coding.
- **Clearer response status**, with waiting and reasoning indicators that disappear as the answer arrives.
- **HTTPS for external Ollama**, with HTTP allowed only for connections on the same device.
