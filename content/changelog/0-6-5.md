You can now connect Moose to NVIDIA NIM and Cloudflare Workers AI. Both include model discovery, streamed responses, and support for reasoning and images when available on the model.

The chat got some attention too. Selecting text is more reliable, Markdown, code and formulas render as the answer arrives, and messages fit their content correctly. Scrolling also behaves better when you want to read earlier content while a response continues.

- Model IDs with spaces work with compatible cloud providers and custom connections.
- Completed responses stay visible in the current chat if saving fails, so you can still read and copy them.
- Managed Ollama stops when you close Moose and prevents conflicting instances from using the same installation.
- Failed or incomplete model downloads report an error.
- App store metadata now links to the project website and includes a contribution link to the repository.

Thanks to [@olumolu](https://github.com/olumolu) for contributing NVIDIA NIM and Cloudflare Workers AI support.
