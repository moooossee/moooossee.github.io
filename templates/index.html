Moose

Chat with local and cloud AI on Linux.

Ask questions, write code and work with your files in a native Linux app. Let Moose install and maintain Ollama for local models, choose a cloud provider, or add your own compatible connection. Conversations, drafts and your document library are saved on your computer.

Features

  • Install, update and repair Moose-managed Ollama while keeping your models and chats.
  • Browse and download local models, review download history and retry interrupted downloads.
  • Attach images, PDFs, text files and code.
  • Search a local document library with source excerpts.
  • Read Markdown, highlighted code and math as answers arrive, and copy tables as Markdown.
  • View model reasoning separately and scroll back through a chat while a response continues.
  • Edit messages, retry answers and keep conversation versions.
  • Save drafts automatically and export your chats.
  • View and copy Moose and Ollama logs, along with model download error details.

Images require a model with vision support. PDFs need selectable text. See Files and documents.

Local and remote models

Custom connections support OpenAI Chat Completions, OpenAI Responses, Anthropic Messages and Google Gemini APIs. Discover models automatically or save their exact IDs, and choose image support for each manual model.

Local Only mode restricts inference to Moose-managed Ollama. Remote connections ask permission before sharing messages; files need separate permission. API keys use your desktop's secret storage.

Keep Ollama up to date

Open Preferences → Ollama & Diagnostics to check for engine updates or repair an installation. Interrupted engine downloads can resume, and a failed update restores the previous installation. Your models, chats and connections stay put.

If a model needs a newer Ollama version, Moose can update its managed installation and retry the download. You can also view recent logs and copy error details when you need help.
