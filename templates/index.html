Features

  • Find models for everyday questions, coding, pictures or documents, with filters for download size and features.
  • Download Ollama and compatible Hugging Face GGUF models by name, link or Ollama command.
  • Install, update and repair Moose-managed Ollama while keeping your models and chats.
  • Search the web, read public pages and check calculations with compatible Ollama and Ollama Cloud models.
  • Attach images, PDFs, text files and code, or search your local document library with source excerpts.
  • Read formatted code, math and model reasoning as answers arrive, and copy tables as Markdown.
  • Edit messages, try another answer or continue an incomplete response while keeping previous versions.
  • Save drafts automatically and export chats with their tool results and web sources.
  • Review downloads, retry failures and copy logs or error details when you need help.

Images require a model with vision support. PDFs need selectable text. See Files and documents.

Find a model for what you want to do

Open Models and choose Everyday, Coding, Images or Documents. Narrow the list by download size, image input, tool support or multiple languages, and compare versions before choosing one.

Model details show estimated memory and storage needs. When Moose manages Ollama, suggestions also consider the memory available on your computer. These are estimates to help you choose; longer chats and images can need more memory. Choose Use beside an installed model to start a chat with it.

Web search and calculations

Look something up or check a calculation without leaving your conversation. With a compatible Ollama or Ollama Cloud model, turn on Web or Calculator in Chat Settings, or type /web or /calculator. You can see what the tools did and read their sources alongside the answer.

Web starts with DuckDuckGo, without a search account. Choose Brave Search, SearXNG or Links Only in Preferences → Web. Web asks for separate permission before first use and is blocked by Local Only mode. Calculator runs on your device; its results are shared with your chat's model.

Use Web and Calculator / Web permissions

Bring models from Hugging Face

Choose Add Model… in Models and paste a Hugging Face repository link. Leave the variant on Automatic, or choose a quantization such as Q4_K_M or an exact GGUF filename. Moose shows the model source and the Ollama connection that will download it.

You can also paste a model link into model search. Installed Hugging Face models link back to their repository, and an already installed chat model can open a new conversation straight from the download dialog.

Choose a GGUF model supported by your Ollama version and suited to the memory available on the device running it.

If your service is not listed, add a custom connection using a compatible API. Moose can find available models or let you add them by name. Images and reasoning options depend on the model you choose.

Local Only mode uses Moose-managed Ollama and blocks cloud connections, external Ollama and web tools. Remote chats ask permission before sharing messages, and files need separate permission. Keys are kept in your desktop's secure key storage.

Keep Ollama up to date

Open Preferences → Ollama & Diagnostics to check for engine updates or repair an installation. Interrupted engine downloads can resume, and a failed update restores the previous installation. Your models, chats and connections stay put.

If a model needs a newer Ollama version, Moose can update its managed installation and retry the download. You can also view recent logs and copy error details when you need help.
