Moose

Chat with local AI on Linux.

Moose is a GTK 4 and libadwaita app for talking to AI models. Run models locally with Ollama, or connect a cloud provider with your own API key. Conversations and drafts are saved on your computer.

Download from Flathub / Source code / v{{ config.extra.version }} release notes

Install

${{ config.extra.install_command }}

Requires Flatpak and the Flathub remote. Moose can install and manage Ollama for you. Getting started

Features

  • Browse, download and manage local models.
  • Attach images, PDFs, text files and code.
  • Search a local document library with source excerpts.
  • Read Markdown, highlighted code, math and model reasoning.
  • Edit messages, retry answers and keep conversation versions.
  • Save drafts automatically and export your chats.

Images require a model with vision support. PDFs need selectable text. See Files and documents.

Local and remote models

Use Ollama managed by Moose, an existing Ollama instance, Ollama Cloud, Groq, OpenAI, Anthropic Claude or Google Gemini.

Local Only mode restricts inference to Moose-managed Ollama. Remote connections ask permission before sharing messages; files need separate permission. API keys use your desktop's secret storage.
